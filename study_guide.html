Module 1

Core Concepts & Glossary

Before diving into files, it's vital to clarify the basic architecture you implemented. The MERN stack represents an end-to-end framework where data resides in a database, is served through a server-side API, and gets beautifully rendered by a client-side interface.

The Big Picture

🌐
Client-Server Model

The Client (browser) sends a request. The Server receives it, retrieves data, and responds with JSON. In your setup, the Client runs on port 3000 and the Server on 5000.

🏗️
The Virtual DOM

React creates a virtual representation of the DOM. When state updates, React builds a new virtual tree, compares it (diffing), and patches the actual browser DOM with only the changes.

🔄
Props vs State

Props are immutable inputs passed by a parent to a child component (read-only). State is local mutable data managed inside the component itself (triggers re-renders on change).

Tools and Libraries We Installed

Express Backend Server

A minimal and flexible web application framework for Node.js. It facilitates defining server routes (e.g., app.get('/api/products')) and handling API requests cleanly.

Mongoose ODM Database Library

Object Data Modeling library for MongoDB. It acts as a bridge, allowing us to enforce structured Schemas (like productSchema) on top of otherwise unstructured MongoDB documents.

Axios HTTP Request Agent

A promise-based HTTP client. React components use Axios in useEffect hooks to fetch API data from your Express backend asynchronously.

React Router DOM Client-Side Router

Allows single-page navigation without full page reloads. Instead of asking the server for a new HTML file, it handles routing inside JS, changing screens instantly based on URL matches.

Concurrently Dev Tool

A developer utility that allows you to run both your frontend server (port 3000) and backend API (port 5000) simultaneously with one single command: npm run dev.

JavaScript Primer
ES6 Syntax
// 1. Object Destructuring (Unpacking properties easily)
const product = { _id: '123', name: 'Camera', price: 89.99 };
const { name, price } = product; // Extracts name and price into individual const variables

// 2. Array Destructuring (Crucial for React Hooks)
const [count, setCount] = useState(0); // useState returns [value, setterFunction]

// 3. Async/Await (Handling asynchronous operations cleanly)
const fetchProducts = async () => {
  try {
    const { data } = await axios.get('/api/products');
    setProducts(data); // Triggers render with new data once request resolves
  } catch (err) {
    console.error(err);
  }
};
